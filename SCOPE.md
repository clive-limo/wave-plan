# Wave Plan - Feature Scope

## V1 (Core MVP) - Current
- [x] Auth (email/password + Google OAuth)
- [x] Dynamic Guilds (CRUD, colors, icons)
- [x] Task system (priorities, time allocation, status)
- [x] Calendar/Planner (week, day, month views)
- [x] Side Quests (categories, playful styling)
- [x] XP & Levels (exponential curve, titles)
- [x] Streaks (consecutive days, multiplier)
- [x] Burnout HP (daily check-in, energy/mood/sleep, HP bar)
- [x] Dashboard (HP, XP, Today's Plan, streaks, energy trend)
- [x] Character Sheet (stats, guild breakdown, energy history)
- [x] PWA (installable, offline shell)

## V2 - Achievements & Depth
- [ ] Achievement/badge system (first task, 7-day streak, 100 tasks, etc.)
- [ ] Daily quests (auto-generated challenges like "complete 3 tasks today")
- [ ] Skill trees per guild (user-defined skills to level up)
- [ ] Task templates / recurring tasks
- [ ] Drag-and-drop planner reordering
- [ ] Hours vs Energy correlation chart on Character Sheet
- [ ] Push notifications (streak reminders, check-in reminders)

## V3 - AI Integration
- [ ] AI-powered task prioritization suggestions
- [ ] Career skill recommendations based on guild activity
- [ ] Burnout prediction (predict low HP before it happens)
- [ ] Smart daily planning (auto-distribute tasks based on energy patterns)
- [ ] Natural language task creation

## V4 - Social & Advanced
- [ ] Loot drops (self-set rewards for task completion)
- [ ] Boss battles (big deadlines with special UI)
- [ ] Social features (invite friends, leaderboards)
- [ ] Team guilds (shared task boards)
- [ ] Weekly/monthly reports

## Future
- [ ] Mobile native app (React Native)
- [ ] Calendar integrations (Google Calendar, Outlook)
- [ ] Project tool integrations (Jira, GitHub Issues, Linear)
- [ ] Pomodoro timer built into task cards
- [ ] Customizable character avatars
- [ ] Themes (dark fantasy, cyberpunk, etc.)
